=== SYSTÈME PNJ/COMPAGNONS ===

• SPAWNER UN PNJ
<<spawn pnj "Nom">>                          // Fait apparaître le PNJ

• GESTION COMPAGNONS
<<pnj "Nom" "buddy">>                        // Devient compagnon
<<pnj "Nom" "follow">>                       // Vous suit
<<pnj "Nom" "fixed">>                        // Reste sur place
<<pnj "Nom" "dead">>                         // Tue le PNJ
<<pnj "Nom" "gone">>                         // Fait partir le PNJ
<<pnj "Nom" "NomPassage">>                   // Déplace vers un passage

• COMMANDES SPÉCIALISÉES COMPAGNONS
<<pnjfollow "Nom">>                          // Vous suit (version améliorée)
<<pnjfix "Nom">>                             // Reste sur place (version améliorée)
<<pnjrecall "Nom">>                          // Rappelle un compagnon absent

• DÉPLACEMENT PRÉCIS
<<movePnj "Nom" "PassageCible">>              // Déplace vers un passage
<<movePnj "Nom" "PassageCible" x y>>          // Déplace avec coordonnées précises
<<pnjCoords "Nom" x y>>                       // Modifie seulement les coordonnées

• SANTÉ COMPAGNONS
<<pnjheal "Nom" quantité>>                   // Soigne le compagnon
<<pnjdamage "Nom" quantité>>                 // Blesse le compagnon
<<pnjkill "Nom">>                            // Tue le compagnon
<<pnjresurrect "Nom">>                       // Ressuscite le compagnon

• STATISTIQUES COMPAGNONS
<<pnjsetstrength "Nom" valeur>>              // Modifie la force
<<pnjsetdexterity "Nom" valeur>>             // Modifie la dextérité
<<pnjsetlevel "Nom" valeur>>                 // Modifie le niveau

• DON D'OBJETS AUX COMPAGNONS
<<pnjgive "NomCompagnon" "id_item">>         // Donne 1 objet
<<pnjgive "NomCompagnon" "id_item" quantité>> // Donne plusieurs objets

• RELATIONS/HUMEUR
<<setrelation "Nom" valeur>>                 // Définit relation (0-100)
<<changerelation "Nom" delta>>               // Modifie relation
<<setloyalty "Nom" valeur>>                  // Définit loyauté (0-100)
<<changeloyalty "Nom" delta>>                // Modifie loyauté
<<setmood "Nom" valeur>>                     // Définit humeur (-2 à 2)
<<changemood "Nom" delta>>                   // Modifie humeur

=== SYSTÈME DE QUÊTES ===

• PROPOSITION DE QUÊTE
<<quest "id" "Titre" "Description courte">>
<<quest "id" "Titre" "Desc courte" "Desc longue">>
<<quest "id" "Titre" "Desc courte" "Desc longue" "{gold:50, items:[]}">>

• GESTION QUÊTES
<<startquest "id">>                          // Démarre une quête proposée
<<markquestready "id">>                      // Marque quête comme terminable
<<markquestcompleted "id">>                  // Termine et donne récompense

=== SYSTÈME DE COORDONNÉES ET CARTE ===

• DÉFINIR COORDONNÉES
<<setcoords x y>>                            // Définit coordonnées du passage
<<setcoords x y "Continent">>                // Avec continent spécifique
<<setcoords {x:1, y:2, continent: "Nom"}>>  // Format objet

• AFFICHER POSITION
<<displaylocation>>                          // Affiche la localisation actuelle
